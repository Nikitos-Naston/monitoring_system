# Проверка сервиса

Дата прогона — 10 ноября 2026. Python 3.12, Paho MQTT 2.1.0,
Starlark-Go 1.0.1, Psycopg 3.3.2. Интеграционный стенд использовал
Aedes 1.2.0 по TCP и PostgreSQL 16.2. Результаты fixture и postgres
на одних и тех же 24 сообщениях совпали.

| Проверка | Результат |
|---|---|
| unittest | 15 тестов прошли |
| MQTT + шаблоны из массивов | 24 сообщения → 24 файла, все 6 профилей |
| MQTT + шаблоны из PostgreSQL | 24 сообщения → 24 файла с теми же результатами |
| Повторная публикация | 24 повторные доставки в каждом режиме, число файлов не увеличилось |
| Неполный блок | Отдельная запись в rejected/ в каждом режиме |
| Потребитель отключён | По одному новому событию в каждом режиме обработано после возврата с тем же client ID |
| Повторный seed-demo | Успешно, существующие строки не продублировались |
| Смена активной версии PostgreSQL | Новое событие записано с версией 2 и тестовым результатом 42 |
| Ошибка запроса PostgreSQL | Потребитель завершился без ACK, после восстановления таблицы сообщение обработано при повторной доставке |

decoded.json содержит исходные 24 результата сквозного прогона,
объединённые в массив для просмотра. В рабочем каталоге сервис пишет
один файл на событие. messages.json содержит соответствующий тестовый вход.

Контейнеры Docker Compose с Mosquitto в этом окружении не запускались.
Тесты выполнялись с другим брокером. Реальный трафик СИ-23, TLS на
целевой инфраструктуре и нагрузка в этот прогон не входили.
